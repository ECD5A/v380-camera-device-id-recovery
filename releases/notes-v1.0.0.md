# v1.0.0 — проверенный пакет для microSD

Первый публичный набор: всё, что нужно для восстановления Device ID, лежит в одном архиве.

**Внутри `microSD-files-only.zip` ровно три файла:**

- `local_update.conf`
- `patch_reuse` — 0 байт, так и должно быть
- `updatepatch/288032472d4d508105188fadf5a3ae8e.patch`

SHA-256 архива: `53c29d2c678efc5f74e814bb8743c7f853bd50b90c88f630c0831ef007b0c18d`

## Что подтверждено

Одна 4G/LTE-камера V380 с модулем **ZXInfoTek ZX800-VG**. Камера создала `update_record` с `last_id`, приложение V380 Pro приняло номер при ручном вводе, владелец подтвердил подключение. Другие модели, Wi-Fi и Ethernet-варианты не проверялись.

## Как использовать

1. Скачайте архив и распакуйте его **в корень** microSD (FAT32).
2. Не переименовывайте файлы и не открывайте `patch_reuse` редактором.
3. Выключите камеру, вставьте карту, включите. Reset не нажимайте.
4. Через ~3 минуты достаньте карту и откройте `update_record` в Блокноте.

## Проверка целостности

```bash
python tools/verify_payload.py
python tools/test_tools.py
```

## Важно

Пакет обрабатывается штатным механизмом обновления прошивки. На несовместимой камере он может изменить служебные данные, вызвать зависание или повредить прошивку. Используйте только на своей камере и на свой риск. Device ID, IMEI, серийные номера и личные записи в проекте не публикуются.
